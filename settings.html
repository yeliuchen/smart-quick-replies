API 配置 ▾

LM Studio 默认可填写 http://localhost:1234/v1，通常不需要 API Key。API Key 仅保存在 SillyTavern Secrets 或明确标注的本地回退位置。

OpenAI-compatible 网关如返回 401，请确认 API Key 和鉴权方式；官方 Google Gemini 使用 Google Gemini (Native)，API Key 会通过 x-goog-api-key 发送。

支持 {{char}} 当前角色名、{{user}} 当前用户名、{{history}} 对话历史和 {{char_description}} 角色描述。若使用 {{history}}，历史会直接放入系统提示词，不再重复发送消息数组。
