# 设置页标题与控件布局设计

## 目标

优化智能快捷回复建议扩展的设置页视觉层级和两个拥挤区域的布局，不改变现有设置 ID、事件绑定或数据流。

## 设计

- 母标签使用轻量标题栏：左侧主题色竖线、紧凑高度、透明背景和右侧折叠箭头，视觉上接近酒馆助手入口。
- 模型选择区把搜索输入框与“获取模型列表”按钮放在同一行，模型结果选择框和状态文字放在下一行；桌面端横向排列，窄屏端自动堆叠。
- 提示词区把“系统提示词”和“恢复默认提示词”放入同一行标题工具栏，文本域保持完整宽度，说明文字位于文本域下方。
- 保留 `sqr-model-search`、`sqr-model-list`、`sqr-fetch-models`、`sqr-system-prompt`、`sqr-reset-prompt` 等既有 ID，确保现有 JavaScript 行为不变。

## 验收

- HTML 结构能表达母标签标题栏、模型工具栏和提示词工具栏。
- CSS 使用现有 ST 主题变量，输入框、选择框和按钮颜色保持一致。
- 模型搜索/获取按钮不会再被模型列表挤到右侧或下移。
- 恢复默认提示词按钮不会单独掉到文本框左下方。
- 现有自动化测试继续通过。
