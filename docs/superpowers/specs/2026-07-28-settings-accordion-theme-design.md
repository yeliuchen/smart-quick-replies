# 设置分页折叠与主题输入框设计

## 目标

改善智能快捷回复建议扩展的设置页：分页内容默认折叠，用户点击任意分页标题即可独立展开或收起，多个分页可以同时展开；同时让设置页内的文本框、密码框、搜索框、数字框、下拉框和多行文本框跟随 SillyTavern 主题，不再显示刺眼的白色背景。

## 根因

当前 `settings.html` 使用顶部标签按钮切换内容区，`index.js` 只在点击标签时将其他区块设置为 `hidden`，没有折叠状态或可点击标题。因此当前标签对应的内容区打开后始终完整展开。

当前 `style.css` 只设置了设置页容器和控件尺寸，没有为控件设置背景色、文字色、边框色或占位文字色。浏览器或主题的默认表单样式因此将部分控件渲染成白底。

## 交互设计

- 保留现有五个顶部分页标签，避免改变用户已经熟悉的导航方式。
- 进入设置页时五个分页内容区默认全部折叠，避免打开扩展设置后出现大片内容。
- 每个内容区标题改为可点击的折叠标题。点击标题只切换当前区块，不影响其他区块，因此允许多个区块同时展开。
- 每个分页卡片始终保留可点击标题，标题和内部内容区通过 `data-sqr-collapse`、`data-sqr-section-content` 与 `aria-expanded` 表达状态；折叠状态只作用于内容区的原生 `hidden` 属性，保证收起后仍能再次展开。
- 分页标题增加展开/收起指示符；标题按钮使用现有主题变量，避免引入固定亮色。
- 点击顶部标签或对应折叠标题后展开目标分页；展开状态保存在当前设置页实例中，不新增持久化配置，避免污染扩展配置契约。

## 主题样式设计

为 `.sqr-settings` 增加表单控件变量，并覆盖以下控件：

- `input`、`select`、`textarea` 的背景使用 `var(--SmartThemeBlurTintColor)`，回退到半透明深色。
- 文字使用 `var(--SmartThemeBodyColor)`，边框使用 `var(--SmartThemeBorderColor)`。
- 占位文字使用低对比度主题颜色；获得焦点时使用主题强调色边框。
- 下拉菜单和模型列表显式设置 `color-scheme` 与 `accent-color`，减少浏览器默认白色控件带来的差异。
- `input[type='range']` 和复选框保留酒馆的原生主题外观，只补充主题强调色。

## 文件边界

- `settings.html`：为五个分页添加始终可见的折叠标题、独立内容区和无障碍属性。
- `index.js`：绑定标题点击事件，维护每个区块的独立展开状态，并保留现有标签切换行为。
- `style.css`：补充折叠标题、指示符和主题表单控件样式。
- `tests/settings.test.js`：验证分页标题结构、默认状态和多区块独立折叠契约。

## 测试与验收

- 测试必须证明五个分页都存在可折叠标题，默认五个分页全部折叠。
- 测试必须证明折叠状态使用区块自身的 `hidden`/`aria-expanded` 契约，而不是强制所有区块互斥。
- 测试必须证明 CSS 覆盖了输入框、选择框和文本域的背景、文字、边框及占位文字颜色。
- `npm test`、`node --check index.js` 和 `git diff --check` 全部通过。
- 不改动 SillyTavern 核心文件，不新增运行时依赖，不改变快捷回复生成流程。
